Public sample-data test of the static browser app. No real office records are included. Use synthetic data only. Records you enter stay in the current browser profile in IndexedDB, not on a server. Export JSON backups; browser data can be cleared or evicted.

This does not verify the Windows installer, native dialogs, printer/scanner hardware or real-data migration. No account, backend or synchronization is included.
